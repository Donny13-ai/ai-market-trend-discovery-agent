# AI Market Trend Discovery Agent

An AI-powered market research automation workflow built in n8n using Google Gemini AI.

## Overview

This workflow automates:
- Amazon product trend analysis
- consumer insight extraction
- visual trend analysis
- AI-generated strategic recommendations
- HTML report generation

The system processes rug category and product data to generate professional market intelligence reports automatically.

---

## Technologies Used

- n8n
- Google Gemini API
- AI Prompt Engineering
- Workflow Automation
- HTML Report Generation
- Data Structuring & Analysis

---

## Workflow Stages

1. Input Parsing
2. Product Data Collection
3. Data Standardization
4. AI Trend Analysis
5. Risk & Buyer Guidance
6. Visual Trend Analysis
7. HTML Report Generation
