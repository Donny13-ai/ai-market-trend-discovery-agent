# AI Market Trend Discovery Agent

An AI-powered market research automation workflow built in n8n using Google Gemini AI.

## Overview

## Overview

This project is an AI-powered market research automation system built in n8n using Google Gemini AI. The workflow collects and processes rug market data, analyzes consumer and visual trends, and generates structured HTML market intelligence reports automatically.

The system demonstrates how AI agents can be orchestrated across multiple workflow stages to automate business research and strategic reporting.
